PharmaCalc BP111P — Combined Practical Virtual Laboratory

This is one standalone HTML file that embeds all four previous BP111P practical apps:
1. Limit tests: chloride, sulphate, iron, lead, arsenic
2. Preparation of inorganic pharmaceuticals: aluminium hydroxide, potash alum, ferrous sulphate, magnesium sulphate
3. Tests for purity: bentonite swelling power, acid-neutralizing capacity of aluminium hydroxide gel, potassium iodate/iodine in potassium iodide
4. Assay of inorganic compounds: ammonium chloride, ferrous sulphate, copper sulphate, calcium gluconate, hydrogen peroxide, sodium benzoate, sodium chloride (modified Volhard)

To run:
1. Extract this ZIP package.
2. Double-click BP111P_BP111P_All_Four_Practical_Labs_Combined.html.
3. Open in current Chrome or Microsoft Edge.
4. Select the section tab at the top. Internet is not required.

Each embedded app retains its own controls, quiz and report/export features. The HTML is self-contained; do not separate it from its embedded data.

Safety/accuracy: educational simulations only. Follow current applicable Indian Pharmacopoeia monographs, prescribed practical manual, institutional SOP and instructor supervision. Verify stoichiometry and factors before using any calculation for actual laboratory work.
